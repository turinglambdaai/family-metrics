# family-metrics

[English](README.md) · **中文**

每日快照记录 TurLamAI 产品家族各仓库的发布下载量，并附带一个零依赖的仪表盘用于读取这些数据。

- `collect.sh` 每天通过 GitHub Actions 定时任务遍历每个产品仓库的 releases API，仅汇总安装包的下载量（排除 sha256/sig/manifest 附属文件），并在 `data/` 下追加一个带日期的文件。文件名中不带版本号的资源（即每次发布都会被覆盖的稳定版各平台别名）会被标记为 `alias`，以便仪表盘将更新渠道的累计流量与各次发布的安装量区分开。某个仓库的 API 调用在中途失败时，该仓库会被跳过并列入当天快照的 `skipped` 项，而不是中止整个运行——仓库改名会被透明地跟随。
- `data/` 每个 UTC 日增加一个文件；`data/index.json` 列出所有文件。
- 仪表盘直接从这些文件渲染——无需构建步骤，无需外部服务。

GitHub 只公开累计计数（以及一个 14 天的流量窗口），因此时间序列仅从快照开始的那一天起才存在：2026-10-15。
